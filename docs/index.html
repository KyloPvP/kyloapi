A plugin

SajatPlugin.java
public final class SajatPlugin extends KitPlugin {

    @Override
    protected void onBoot() {
        CombatVisuals.enable(this);   // damage popup + combo
        ChatEngine.start(this);        // chat csatornák
        NpcKit.register(this);         // NPC rendszer
    }
}

A KitPlugin az onDisable-ben automatikusan megteszi: ChatEngine.cleanup(), PacketEventsHook.terminate(), ConfigFile.saveAllRegistered() és a Kit.shutdown(). Kezi plugin esetén ezeket az hu.paperkit.core.Kit osztály hívásai végzik el: Kit.init(plugin) / Kit.shutdown().

💬Chat Engine

Saját chat-formázás csatornákba szervezve: prefix, hover, kattintás, jogosultság, helyi (rész csatornák szabású) üzenetek, slow-mode — mindez kódból vagy chat.yml-ből.

  • ChatEngine start(plugin) // alap "global" csatorna
  • loadFromConfig(plugin) // csatornák a chat.yml-ből
  • registerChannel(Channel)   setDefaultChannel(id)
  • setSlowMode(id, seconds)   setIntercepting(bool)
  • send(player, channelId, message)
  • Channel Channel.global(format) / .create(id, format) / .local(format, blocks)
  • Channel .prefix(mini) .hover(mini) .suggest(cmd) .run(cmd)
  • .permission(node) .range(blocks) .nameColor(tag)

Kód példa

ChatEngine.java
ChatEngine.start(this);

ChatEngine.registerChannel(
    Channel.global("<dark_gray>[<aqua>G<dark_gray>] {name}<gray>: </gray>{message}")
           .hover("<gray>Játékos: <white>{player}")
           .suggest("/msg {player} "));

ChatEngine.registerChannel(
    Channel.create("staff", "<dark_red>[STAFF] {name}: {message}")
           .permission("myp.chat.staff"));

ChatEngine.setSlowMode("global", 3);   // 3 mp várakozás

chat.yml-s ban JSON-kimenet

chat.yml
default: global
channels:
  global:
    format: "<dark_gray>[<aqua>G<dark_gray>] {name}<gray>: </gray>{message}"
    suggest: "/msg {player} "
  staff:
    format: "<dark_red>[STAFF] {name}: {message}"
    permission: "myp.chat.staff"
  local:
    format: "<green>[L] {name}: {message}"
    range: 30        # csak 30 blokk
slow-mode-seconds:
  global: 3

Tokenek: {prefix}, {name} (.hover-el), {player}, {message} — — játékoslap: %placeholder% (a PaperKit/KyloAPI Placeholders estefolyón).

🗂️Config & Formula

ConfigFile: jar-be vett factory, Yaml-olvasás/írás tipusosan, szekciók. Formula: matematikai kifejezés-evaluator a "formula / manual" config-mintához.

  • ConfigFile ConfigFile.load(plugin, "config.yml")
  • getString / getInt / getBoolean / getDouble(path, default)
  • .set(path, value) / .save() / .saveIfChanged() / .reload()
  • Section .node(path)   List .keys(path)
  • Formula Formula.compile("2 ^ %level% * 30")
  • .evalInt(Map.of("level", szint)) / .eval(vars) admínio
  • int Formula.calculate(config, path, "level", szint)
config.yml + Formula
# config.yml — a kész pluginók konfig-mintája:
xp-szukseges:
  type: "formula"              # vagy "manual"
  formula: "%level% ^ 2 * 100"
  manual:
    1: "100"
    2: "500"
Java
ConfigFile cfg = ConfigFile.load(this, "config.yml");
int szukseges = Formula.calculate(cfg, "xp-szukseges", "level", szint);
// vagy:
int szinten = Formula.compile("/szimulast").evalInt("level", 5);

🧭Parancsok (CommandKit)

Sub-parancs router: permission, alias, playerOnly, tab-completion, argumentum-olvasás — mindegyik Security-a Biztonság Bell-mett —, plugin.yml gondtal.

Router
// plugin.yml-ben: "shop" parancs definialva
CommandKit.route(this, "shop", root -> {

    root.sub("give")
        .permission("shop.give")
        .playerOnly()
        .minArgs(2)
        .usage("<jatekos> <osszeg>")
        .on(ctx -> {
            Player celpont = ctx.argPlayer(0);
            int osszeg = ctx.argInt(1, 0);
            // give logika...
        })
        .tab(0, input -> List.of("KyloPvP", "Jatekos2"));

    root.sub("reload")
        .permission("shop.reload")
        .on(ctx -> cfg.reload());
});

CommandContext: sender(), player(), arg(i, default), argInt(i, default), argPlayer(i), argCount().

🎟️Voucher Engine új

Vásárlásra/küldésre használható kupon-itemek: jobb-klikkre meghívott saját kód, PDC-alapú felismerés, esiledle (még ablak), cooldown és mennyivéret methódus átadás. Egy .stamp() hívással bármelyik item lesz voucher.

Példa — pénzkupon
VoucherKit.register(this);

var kupon = VoucherKit.voucher("money-500")
        .onRedeem((player, item) -> {
            VaultHook.give(player, 500);   // vagy saját logika
        })
        .consumeItem(true)          // az item elhasználódjon
        .successMessage("<green>500 $ jóváírva!")
        .register();

// az item elkészítése és odaadása:
var item = kupon.stamp(
    ItemBuilder.of(Material.PAPER)
            .name("<gold>500 $ kupon")
            .lore("<gray>Kattints a beváltáshoz!")
            .build());
player.getInventory().addItem(item);

DatabaseKit: SQLite (a server tartalmazza a drivert) és MySQL — paraméterezett query/update, minden szálbiztos. StatKit: tetszőleges statisztika per-játékos (cache + async mentés + leaderboard).

  • DatabaseKit DatabaseKit.open(plugin, "adatok.db") — SQLite
  • DatabaseKit.open("jdbc:mysql://host/db", user, pass) — MySQL
  • .table(name, "uuid TEXT", "value REAL"…) / .update(sql, params…)
  • .query(sql, params…) → List<Map> / .firstValue(sql, col, params…)
  • StatKit StatKit.open(plugin, db) / add(player, key, amount)
  • .set(player, key, value) / .get(player, key)
  • .top(key, limit) → List<Entry> / sendTop(viewer, key, limit)
  • .flush() / .autoFlush(seconds) / .close()
Példák
var db = DatabaseKit.open(this, "kylo.db");
db.table("vyelendusers", "uuid TEXT", "name TEXT", "money REAL");
db.update("INSERT INTO vyelendusers VALUES (?, ?, ?)",
        player.getUniqueId(), player.getName(), 0.0);

StatKit.open(this, db);
StatKit.add(player, "kills", 1);
StatisticKit.sendTop(viewer, "kills", 10);
StatKit.autoFlush(60);    // percenkénti mentés
