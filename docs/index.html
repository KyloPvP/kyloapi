📦Modulok

🖥️ Menu & GUI kész

Inventory GUI-k, PagedMenu, Confirm, Anvil/Chat input, yaml-ból definiálható menük a GuiLoader-rel.

💬 Chat Engine kész

Csatornák, formázás, hover/click a neveken, local chat, staff csatorna, chat.yml sablon + slow-mode.

🎨 Text & Colors kész

MiniMessage + legacy + HEX, gradient, title, actionbar, Messages (lang.yml-stílus) és Localization.

✨ Display & Hologram kész

TextDisplay/ItemDisplay builder, animációk, hologramok, követő smart-hologram.

⚔️ Combat Visuals új

Damage popup, critical-felismerés, combo counter — egy CombatVisuals.enable() hívással.

🖥️ HUD Engine új

Health/Mana/Stamina sávok és progress-widgetek bossbaron, formázható tokenekkel.

🧍 NPC & Dialogue új

Per-player NPC-k (NpcKit) és időzített beszélgetések chat-válaszokkal (DialogueKit).

🎥 Cinematic új

Kameraútvonalak smooth easing-gel (cosine), megszakítás támogatás.

🌫️ Fake render új

Per-player blokkok (FakeBlockKit) és fake mobok (FakeEntityKit — packet-alapú).

⚡ Ability Engine új

Item-képességek: cooldown, permission, left/right/hit handler, PDC-alapú felismerés.

💠 Particle + Presets kész

Circle/sphere/spiral/beam/aura + kész effekt- és GUI-pretész-könyvtár.

🍖 Sound & Task kész

3D hangok, időzített szekvenciák, Cooldown és Sequence builder.

💬Chat Engine

Csatornák kódból vagy chat.yml-ből, slow-mode, jogosultság, local-range, hover & click:

chat.yml 
default: global
channels:
  global:
    format: "<dark_gray>[<aqua>G<dark_gray>] {name}<gray>: </gray>{message}"
    hover: "<gray>Játékos: <white>{player}"
    suggest: "/msg {player} "
slow-mode-seconds:
  global: 3

🚀Kezdés 10 másodperc alatt

1) add a függőséget · 2) extends KitPlugin · 3) használd bátran

SajatPlugin.java 
public final class SajatPlugin extends KitPlugin {
    @Override
    protected void onBoot() {
        CombatVisuals.enable(this);
        ChatEngine.start(this);

        // az első NPC 3 sorban
        NpcKit.spawn(player.getLocation(), "<gold>Mester");
    }
}
