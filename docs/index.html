💬Chat Engine

Csatornák kódból vagy chat.yml-ből — slow-mode, jogosultság, local-range, hover & click:

chat.yml 
default: global
channels:
  global:
    format: "<dark_gray>[<aqua>G<dark_gray>] {name}<gray>: </gray>{message}"
    hover: "<gray>Játékos: <white>{player}"
    suggest: "/msg {player} "
slow-mode-seconds:
  global: 3

🚀Kezdés 10 másodperc alatt

1) add a függőséget · 2) extends KitPlugin · 3) használd bátran

SajatPlugin.java 
public final class SajatPlugin extends KitPlugin {
    @Override
    protected void onBoot() {
        CombatVisuals.enable(this);
        ChatEngine.start(this);

        // az első NPC 3 sorban
        NpcKit.spawn(player.getLocation(), "<gold>Mester");
    }
}
